# Skill vocabulary

The ONLY tags allowed in `[tags]` on fact lines and in `skills:` frontmatter.
`scripts/build_index.py` warns about any tag not listed here.

How to use: map every requirement in a job posting to tags via the Synonyms column
(English and Norwegian), then search for those tags. Add a new row when a genuinely
new skill appears; prefer adding a synonym to an existing row over creating a near-duplicate tag.
